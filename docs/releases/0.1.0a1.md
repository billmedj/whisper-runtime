# 0.1.0a1 — alpha

Date: 2026-09-07.

This is an experimental Python SDK and installed CLI, not a stable V0.1 release.
The native transcription scope is English, mono 16 kHz audio and the pinned
`tiny.en` model/backend. The runtime keeps provisional text separate from
committed captions and exports TXT, SRT and VTT only after a real FINAL.

For low-latency evaluation, explicitly select `--profile low-latency-v2`
(or `profile="low-latency-v2"` in the native factory). This is the recommended
experimental profile for this alpha. It uses retained context, alignment-feature
reuse and two-observation holdback without speculative draft tokens. CUDA startup
prepares the aligner's CPU backtrace before accepting audio; it does not warm
model inference or Triton kernels. The omitted-profile default remains
`conservative-v1`; existing versioned profiles are unchanged.

## What was checked

Two identical 46.55-second source-paced sessions passed on one T4 with the same
model and worker. First nonempty confirmed text arrived at 7.358 s and 6.186 s
after readiness. The largest observed gap between text-growing confirmations
was 7.679 s. Both sessions reached FINAL with full 744,800-sample coverage,
restored runtime capacity and identical TXT/SRT/VTT hashes. Each transcript had
7 word edits against the 114-word reference; this is not independent accuracy
coverage. These timings exclude setup, transport and display and do not establish
a per-word or universal eight-second latency bound.

See the [measured results](../research/2026-09-07-low-latency-v2-gpu-results.md)
and [verified evidence archive](../../evidence/modal-low-latency-v2-2026-09-07.zip).

## What this alpha does not guarantee

The four-hour native endurance test, physical microphone capture, GUI integration
and clean-OS installation coverage remain open. The short run is not a production
reliability guarantee. Its submitted 4 GiB resource limit and guest memory
counters do not independently verify physical host RAM; the earlier absolute
3.5 GiB guest-RSS gate remains failed and unchanged.

Start with the [CLI guide](../CLI.md). Native dependencies and the verified local
model/backend setup are separate from installing the dependency-free runtime.
