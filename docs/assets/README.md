## Colors and type

| Color | Hex | Use |
| --- | --- | --- |
| Teal | `#087E8B` | Mark, arrows and confirmed-text underline |
| Dark teal | `#12343B` | Main text |
| Light teal | `#EAF6F4` | Card background |
| Grey | `#52666A` | Preview text and notes |
| White | `#FFFFFF` | Diagram background |

Headings use Arial Nova with Helvetica and Arial fallbacks. Body text uses
Segoe UI; data labels use Consolas. Fonts are not bundled. Keep the mark's
proportions and leave at least one stroke width of space around it.

Use plain labels in diagrams. Put the detailed explanation in the linked guide.
Examples should look different from measured results and be labeled as examples.
