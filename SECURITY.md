# Security policy

## Supported versions

This project is pre-alpha. Only the current `main` branch receives security
fixes. No release is approved for production use.

## Report a vulnerability

Use GitHub private vulnerability reporting for security defects. Do not open a
public issue for an unpatched vulnerability.

Include the affected revision, impact, prerequisites, and a minimal
reproduction. Do not include credentials, private audio, model files, or other
sensitive data.

Public issues are appropriate for ordinary correctness, compatibility, and
documentation defects.
